# M0 — Install the Claude Code Bridge on a fresh Windows 11 PC

**Audience:** Someone who has never touched PowerShell. We assume nothing about your machine except that it's running Windows 11 with an internet connection.

**Time:** 1–3 minutes from download to working bridge.

---

## The one-click path (recommended)

1. Download **[`Install-Claude-Code-Bridge.bat`](https://raw.githubusercontent.com/johncliechty/claude-code-bridge/main/Install-Claude-Code-Bridge.bat)** — right-click the link → "Save link as…" → save to your Desktop.
2. **Double-click** the file you just downloaded.
3. A black window appears with a brief summary of what will happen. Press **Y** to continue.
4. The installer runs. You'll see status lines like `PASS: Python at …`, `PASS: Scheduled task registered`, etc. If Python is already installed it will be detected and reused — no reinstall.
5. When you see `BOOTSTRAP COMPLETE` and `Install completed successfully`, press any key to close the window. You're done.

That's it. No PowerShell commands to copy or paste.

> **Windows SmartScreen note.** Windows may show a blue "Windows protected your PC" panel when you double-click a downloaded `.bat`. Click **More info** → **Run anyway**. This is normal for any unsigned downloadable installer.

---

## What the installer does, step by step

The `.bat` launches PowerShell silently and runs `bootstrap.ps1` from the repo. `bootstrap.ps1` does five things in order:

| Step | What | What you might see |
|---|---|---|
| 1 | Ensure Python 3.10+ is present. Search 12 known install paths first. Only if nothing is found, install Python 3.13 via `winget` (user scope, no admin). | `PASS: Python at C:\Users\<you>\AppData\Local\Programs\Python\Python313\python.exe` (existing install) **or** `Installing Python 3.13 via winget …` (first-time install) |
| 2 | Ensure `git` is present. If missing, install via winget. | `PASS: git at …` or `Installing Git via winget …` |
| 3 | Clone the bridge repo from GitHub to `C:\dev\claude-code-bridge`. If already cloned, pull the latest. | `Cloning … -> C:\dev\claude-code-bridge` or `PASS: Repo already present` |
| 4 | Create a virtual environment (`.venv`) inside the repo and run `pip install -e .`. This makes the `.claude-plugin/` MCP entrypoint work. | `PASS: Bridge package installed in venv` |
| 5 | Run `install-watcher.ps1`. This registers a Windows Scheduled Task (`ClaudeCodeBridgeWatcher`) that auto-starts the daemon at logon, then spawns it now and runs a six-step self-test (Python check, import test, scheduled-task registration, daemon spawn, end-to-end round-trip, destructive-op gate). | A series of `PASS:` lines ending with `INSTALL COMPLETE` |

If any step fails, the installer stops and shows you what failed. Common failures and fixes are below.

## What "success" looks like

After the installer closes, you can prove the bridge is alive by opening a PowerShell window and running one command (see "How to open PowerShell" below if you've never done that):

```powershell
Get-ScheduledTask -TaskName ClaudeCodeBridgeWatcher
```

You should see `ClaudeCodeBridgeWatcher` listed with `State: Ready` or `Running`.

In a Cowork chat, the agent can now call the `run_command` MCP tool and shell commands will actually execute on your PC. The `IPC inbox` and `IPC outbox` folders are at `C:\dev\claude-code-bridge\ipc\`.

## Common failures and what to do

### "Windows protected your PC" SmartScreen panel

Click **More info** → **Run anyway**. This appears once on first run of any unsigned downloaded `.bat`.

### "winget is not recognized"

Windows 11 ships with `winget` by default. If you see this error, you may be on a very old build of Windows 11 or have App Installer disabled. Open the Microsoft Store, search for "App Installer", and install / update it. Then re-run the installer.

### "Python was installed but is not yet resolvable"

Windows propagates PATH changes per-process. If `winget` just installed Python in the same shell that's looking for it, the shell's PATH is out of date. **Close the installer window, then double-click `Install-Claude-Code-Bridge.bat` again.** The second run sees the freshly-installed Python.

### "git clone failed"

Most likely a network problem or your corporate proxy. Try again on a different network. If still failing, install Git for Windows manually from <https://git-scm.com/download/win> and re-run.

### Step 2 says `bridge.shell import failed`

The Python install completed but the bridge module won't import. Almost always a partial / corrupted Python install. Uninstall Python via **Settings → Apps → Installed apps**, then re-run the installer (it will re-install cleanly).

### Step 5 says `No response from daemon within 15s`

The daemon spawned but didn't respond to a test request. Open the log to see what crashed:

```powershell
Get-Content C:\dev\claude-code-bridge\logs\watcher.log -Tail 40
```

The last error in the log is your starting point. Most common cause: another process already holding `C:\dev\claude-code-bridge\ipc\inbox\` (rare). Restart the PC and re-run the installer.

## How to open PowerShell (for the curious or the diagnostic-needing)

You don't need to open PowerShell at all for the one-click install. But if a failure asks you to run a diagnostic, here's how:

**Windows 11:**

1. Right-click the **Start** button (Windows logo, bottom-left of the screen).
2. Choose **Terminal**. (On older Windows 11 builds: **Windows PowerShell** or **Windows PowerShell (Admin)**.)
3. A dark blue/black window appears with a `PS C:\Users\<you>>` prompt. That's PowerShell. Type commands, press Enter.

**Alternative:** press `Win+X`, then `i` (this opens Terminal directly).

You can close the window any time with the X in the corner or by typing `exit`.

## Uninstall

```powershell
# Stop and unregister the Scheduled Task
Unregister-ScheduledTask -TaskName ClaudeCodeBridgeWatcher -Confirm:$false

# (Optional) Delete the repo
Remove-Item -Path C:\dev\claude-code-bridge -Recurse -Force
```

Python and git stay installed (they may be used by other software). Uninstall them via **Settings → Apps → Installed apps** if you want them gone.

---

## Two-command form (for users who'd rather see what's happening)

If you'd prefer to drive the install from PowerShell directly instead of using the `.bat`, these two commands do the same thing:

```powershell
# 1) Clone the repo
git clone https://github.com/johncliechty/claude-code-bridge C:\dev\claude-code-bridge

# 2) Run the bootstrap (Python check, venv setup, daemon registration)
powershell -NoProfile -ExecutionPolicy Bypass -File C:\dev\claude-code-bridge\bootstrap.ps1
```

The `.bat` is just a thin wrapper over `bootstrap.ps1`.

## What this is, in one paragraph

The Claude Code Bridge is a small Python daemon that runs on your Windows PC and lets a sandboxed AI agent (Cowork, Cursor, etc.) execute shell commands on your machine through a structured request/response file protocol. Destructive operations (`rm -rf`, force-push, format-volume, etc.) are blocked by default. Admin elevation requests are flagged but not auto-elevated. The daemon's source is at <https://github.com/johncliechty/claude-code-bridge> — read `bridge/watcher.py` for the protocol details.
